Новый проект, способный как прятаться за чужим доменным именем, так и использовать собственное с сайтом заглушкой отдающимся nginx в том же контейнере. 
```
SELFSTEAL=1
DOM=your_domain.com
UUID=
SID=
PRK=
PBK=
XHTTP_PATH=
GRPC_NAME=
HY2_OBFS_PORT=40443

ACME_STAGING=0
SKIP_DNS_CHECK=0
HY2_PLAIN=1

#немного српавки по переменным
# SELFSTEAL - самое критичное, если 1 то нужен свой домен в параметре DOM направленный на IP сервера, если 0, то воруем чужой по типу www.cloudflare.com
# ACME_STAGING=0 для тестов, можно указать 1 для не боевого сертификата
# HY2_PLAIN - 1 # истерия на 443 включена при 1, и выключена при 0. 0 стоит ставить если задача - прятаться за чужим доменом, а не selfsteal
# HY2_OBFS_PORT=40443 порт где будет лежать истерия с обфускацией саламандра
```
В нем предусмотрены все актуальные транспорты VLESS, а также истерия 2 в двух вариантах, стандарт и quick обфускацией саламандра. Порты нужны следующие 80 443 8443 2053 40443 (последний определяется через переменную HY2_OBFS_PORT, все остальные  стандартные)

Сразу перейду к делу и распишу два варианта и алгоритма использования:


ПЕРВЫЙ - У ВАС ЕСТЬ СВОЕ ДОМЕННОЕ ИМЯ

1) Направляем доменное имя на иностранный сервер (указываем его IP в А-записи домена/поддомена) и ждем когда настройки применятся
2) Открываем все нужные порты на сервере (указаны выше). Включая 80 ЭТО ВАЖНО для проверки сервера и получении LE-серта
3) Делаем git clone и ставим докер, затем смотрим на три важные переменные в .env , т.к. используем свой домен то смотрим что:
```
SELFSTEAL=1 - используем собственный сайт для пряток
DOM=your_domain.com - указываем собственный дотмен/поддомен
HY2_PLAIN=1 - добавляем обычную истерию 2 на 443-ем порту по udp без доп обфускации (это ок)
```
остальные переменные можно не заполнять, или заполнить тем что уже было, по ситуации, расписывать не буду, т.к. ноунеймам этот репозиторий не попадется, а те кто о нем знают - поголовно айтишники
4) Затем делаем docker compose up -d  и ждем пока все соберется и запустится + еще пол минуты для отправки заявки на серт и т.д.
5) запускаем скрипт server_info.sh для получения ссылок для подключения. Которые нужно просто скопировать и вставить в HAPP
6) Настраиваем маршрутизацию на стороне клиента
7) Можем открыть свой домен прямо в браузере и увидеть маскировочный сайт, если что-то не так - дебажьте, в первую очередь чекайте логи контейнера через docker logs container_id


ВТОРОЙ - ДОМЕННОГО ИМЕНИ НЕТ

1) Делаем git clone и ставим докер, затем смотрим на три важные переменные в .env , т.к. своего домена нет, смотрим что:
```
SELFSTEAL=0 - используем чужой сайт для пряток, свой не поднимаем
DOM=your_domain.com - указываем чужой дотмен/поддомен по типу cloudflare но лучше что-то менее известное с TLS 1.3
HY2_PLAIN=0 - убираем обычную истерию 2 на 443-ем порту по udp без доп обфускации, та что на 40443 по умолчанию с обфускацией останется. Почему эту стоит убрать? потому что ей тяжело будет маскироваться без реального серта, что может спалить сервер в теории
```
остальные переменные можно не заполнять, или заполнить тем что уже было, по ситуации, расписывать не буду, т.к. ноунеймам этот репозиторий не попадется, а те кто о нем знают - поголовно айтишники
2) Затем делаем docker compose up -d  и ждем пока все соберется и запустится + еще пол минуты для отправки заявки на серт и т.д.
3) запускаем скрипт server_info.sh для получения ссылок для подключения. Которые нужно просто скопировать и вставить в HAPP
4) Настраиваем маршрутизацию на стороне клиента

Хранилища сертов/проверки/сертбот работают штатно, env можно сохранять с последующим переприменением ключей.
