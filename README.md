пока максимально кратко, это мой новый проект для тестирования селфстиал с реалити + истерией с настоящими сертификатами и возможностью менять маскировку с чужого домена на свой. 

Предусмотрены все актуальные транспорты + истерия в двух вариантах, стандарт и quick обфускацией. Порты нужны следующие 443 8443 2053 40443 (последний определяется через переменную HY2_OBFS_PORT, все остальные  стандартные). 

Пока что отсутствует проверка на то направлен ли домен/нет, вероятно имплементирую в дальнейшем после тестов. Но костяк уже работает, хранилища сертов/проверки/сертбот работают штатно, env можно сохранять с последующим переприменением ключей. 

Также присуствует приятная заглушка сайта для маскировки. Проверки LE сервер проходит. Все это пакуется в один контейнер для удобства.
